A collection of enterprise virtual job simulations I've completed through Forage, covering security operations, risk assessment, threat analysis, and incident response across four organizations.
 
Each simulation below links to a dedicated page with the program overview, the tasks I completed, and the skills demonstrated.

### About these simulations

These are self-paced, task-based programs designed by each company to mirror real day-to-day work on their security teams — not graded coursework, but hands-on scenarios with deliverables I produced myself (advisory emails, scripts, reports, and presentations).
