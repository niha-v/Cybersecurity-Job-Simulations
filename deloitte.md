# Deloitte Australia — Cyber Job Simulation

**Role simulated:** Cyber security consultant, Deloitte Australia

Deloitte's simulation is framed around supporting a client through a live cyber security breach — investigating how private company information leaked and tracing the activity back to its source.

### Task 1 — Cyber Security Investigation

- Supported a simulated client through a cyber security breach involving a leak of private company information
- Read and interpreted web activity logs to trace the incident
- Answered targeted questions to identify suspicious user activity and determine the likely source of the breach

### Skills demonstrated
`log analysis` · `incident investigation` · `client-facing security consulting` · `attack source identification`
