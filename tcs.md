# Tata Consultancy Services (TCS) — Cybersecurity IAM Developer Job Simulation

**Role simulated:** Identity and Access Management (IAM) Developer, Cybersecurity Consulting division

Stepped into TCS's Cybersecurity Consulting division to help strengthen the security posture of **TechCorp Enterprises**, a global technology conglomerate under pressure to tighten cybersecurity following a wave of industry data breaches.

**Team context:** worked alongside a simulated IAM project team — Priya (IAM Architect, project lead), Rajesh (IAM Business Analyst), and Ankit (IAM Engineer) — kicked off via a project briefing outlining three deliverables: an IAM readiness assessment, a tailored IAM solution design, and an IAM platform implementation plan.

### Project scope

1. **IAM readiness assessment** — evaluate TechCorp's current readiness for IAM implementation
2. **IAM solution design** — craft a customized IAM solution aligned with TechCorp's business processes and security objectives
3. **IAM implementation plan** — plan the rollout of an IAM platform, addressing integration challenges and ensuring secure access to digital resources

### Task 1 — IAM Readiness Assessment

Kicked off with a project briefing from Priya (IAM Architect, project lead) covering TechCorp's profile: a 150,000+ employee technology conglomerate operating in 100+ countries, mid-way through a digital transformation and increasingly concerned about data breaches given its expanding digital footprint.

- Built a comprehensive IAM readiness checklist covering six focus areas: user lifecycle management, access control mechanisms, compliance and governance, integration with existing systems, cloud services integration, and user experience
- Tailored the assessment to TechCorp's scale — factoring in multi-jurisdictional compliance, legacy system integration, and the need for a solution that could support 150,000+ users without becoming an operational bottleneck
- Delivered the checklist as a stakeholder-facing email response, summarizing key considerations alongside the actionable checklist itself

### Task 2 — IAM Solution Design

Based on the readiness assessment, the team identified two priority focus areas: strengthening user lifecycle management and access control mechanisms. I designed tailored solutions for both, delivered as a formal design document.

- **User lifecycle management:** proposed an automated Identity Governance and Administration (IGA) platform tied directly to HR system (HRIS) events — automatic provisioning on hire, immediate de-provisioning on termination, and access adjustment on role change, replacing error-prone manual processes
- **Access control mechanisms:** proposed RBAC as the primary access model, enforced through least privilege, layered with MFA for sensitive and privileged access, plus continuous audit logging and monitoring
- For each solution, documented alignment with TechCorp's existing business processes, alignment with broader business objectives (security, user experience, competitive edge), and the rationale behind each design choice (e.g., RBAC over ABAC as the primary model given TechCorp's scale)

### Task 3 — IAM Platform Implementation Plan

Translated the solution designs into an actionable rollout plan, delivered as a PowerPoint presentation for stakeholders.

- Structured the plan around 8 implementation phases — project initiation, needs assessment, solution design, resource planning, implementation, testing & QA, deployment, and monitoring & optimisation — each with milestones, timelines, and resourcing
- Directly addressed the three core integration challenges from TCS's IAM methodology: a diverse application ecosystem (legacy on-prem systems, cloud apps, proprietary CRM/ERP), data synchronization across systems, and preserving user experience — pairing each with a concrete mitigation (protocol standardization via OAuth 2.0/SAML, HRIS-triggered automation, and SSO)
- Tied the full implementation plan back to TechCorp's business goals: enhanced cybersecurity, streamlined operations, improved user experience, and sustaining a competitive edge through secure, confident scaling

### Skills demonstrated
`identity and access management (IAM)` · `security posture assessment` · `solution design` · `implementation planning` · `stakeholder communication` · `enterprise security consulting` · `presentation design`
